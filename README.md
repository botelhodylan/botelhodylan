## Current project: SSF Companion

A downloadable, local-first desktop companion for Path of Exile 1 Solo Self-Found players. It helps turn build imports and player-provided game data into a reviewable progression route.

- [Project source and documentation](https://github.com/botelhodylan/ssf-companion)
- [Windows preview download](https://github.com/botelhodylan/ssf-companion/releases/tag/preview-v0.2.4)
- [Bug reports and feature requests](https://github.com/botelhodylan/ssf-companion/issues)

The current Windows preview is unsigned; its release includes a SHA-256 checksum. The README explains the app's current scope, data handling, and limitations.
